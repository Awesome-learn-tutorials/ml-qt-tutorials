第二章

行情数据与金融特征工程

从ML视角重新认识金融数据：低信噪比、非平稳、高度相关

2.1 引言

在机器学习的经典教学中，数据通常以整洁的 CSV 文件呈现——特征含义明确、标签精准、样本之间相互独立。MNIST 的像素矩阵、Iris 的花瓣测量值、MovieLens 的评分记录，都是"友好"的数据集。然而，当你将同样的建模思路搬到金融市场，迎面而来的却是一个截然不同的数据世界。

金融数据是量化交易的基石。无论你使用的是简单的线性回归还是深度强化学习，模型的表现上限由数据质量决定。所谓 "Garbage In, Garbage Out" 在金融领域尤为显著——不仅因为数据本身噪声极大，更因为数据处理中的微小错误（如未来信息泄露）会导致回测结果与实盘表现天差地别。

本章将系统性地介绍A股市场中可用的数据类型、不同数据频率的选择逻辑、金融数据对ML基本假设的挑战，以及从原始行情到可建模特征的工程流程。对于有ML背景的读者，本章的核心目标是帮助你理解：为什么在金融数据上，你在其他领域积累的直觉可能会失效，以及如何调整你的方法论来适应这个"最嘈杂的信号源"。

2.2 数据类型分类

A股市场的数据来源丰富，按性质可分为三大类。每类数据有不同的更新频率、获取难度和适用场景。下表是一个概览：

数据类型 具体内容 更新频率 适用策略类型
行情数据 OHLCV（开高低收量）、Level-2盘口（买卖五档/十档）、逐笔成交 实时（Tick级到日频） 日内策略、中频策略、技术分析类策略
基本面数据 财务报表（利润表/资产负债表/现金流量表）、分析师一致预期、公司公告、行业数据 季度更新 / 事件驱动 基本面选股、价值投资、多因子模型
另类数据 新闻舆情、社交媒体情绪、卫星遥感图像、资金流向（北向/融资融券）、龙虎榜、大宗交易 不定期 / 日内到日频 事件驱动策略、情绪策略、资金流策略

行情数据是最基础也是最容易获取的数据类型。日频 OHLCV 数据可以从多个免费数据源获得（如 Tushare、AkShare、BaoStock 等），而 Level-2 盘口数据和逐笔成交数据则通常需要付费购买。对于初学者而言，日频数据已经足够构建大部分经典策略。

基本面数据的核心挑战在于"时间点"（Point-in-Time）问题——稍后会详细讨论。你需要知道的是：财务数据有报告期和发布期的区别，使用不当就会引入未来信息。此外，A股上市公司的财报质量参差不齐，数据清洗工作量不容小觑。

另类数据近年来在量化领域异军突起。例如，通过 NLP 模型分析东方财富股吧的发帖情绪、通过卫星图像分析零售企业停车场的车辆数量、通过龙虎榜数据追踪游资动向等。这类数据的优势是信息含量可能尚未被市场充分定价，劣势是获取成本高、处理难度大、有效周期可能较短。

2.3 数据频率的选择

数据频率的选择决定了策略的时间尺度和交易逻辑。对于ML量化策略而言，这不仅是一个业务决策，更直接影响样本量、特征工程方式和模型训练的计算开销。

日频及以上（日线/周线）

  • 适用于因子选股、多因子模型
  • 数据量适中：全市场约5000只股票 x 250交易日 = 每年125万条记录
  • 信号相对稳定，换手率低
  • 交易成本影响较小
  • 反应速度慢，无法捕捉日内机会
  • 可使用的免费数据源多

分钟频/Tick级

  • 适用于高频策略、日内择时、做市策略
  • 数据量巨大：全市场1分钟线每天约120万条
  • 信号反应快，但噪声极大
  • 交易成本是核心考量（A股T+1限制）
  • 需要低延迟基础设施
  • 数据获取成本高，存储需求大

对于大多数ML量化研究者——尤其是个人投资者和中小团队——日频数据是最优起点。原因有三：第一，日频数据免费可得、质量可靠；第二，日频策略的交易成本相对可控，不需要精确到毫秒的执行系统；第三，学术界绝大多数因子研究成果都基于日频或更低频率，可以直接复现和验证。

需要特别强调的是，A股市场的 T+1 交易规则（当日买入的股票次日才能卖出）使得真正意义上的高频交易在股票现货市场受到极大限制。日内策略在A股中更多依赖于期货和期权市场，或者通过底仓策略间接实现日内交易。因此，本教程后续章节将主要以日频数据为基础展开讨论。

2.4 金融数据对ML假设的挑战

这是本章最重要的部分。机器学习的标准流程基于一系列假设——样本独立同分布（i.i.d.）、信噪比合理、特征空间稳定、训练集和测试集来自同一分布。金融数据几乎违背了所有这些假设。理解这些挑战是避免"回测很美、实盘亏钱"陷阱的关键。

2.4.1 极低信噪比

关键对比：在图像分类任务中，模型的准确率通常可以达到 95%+（R² 接近 1）；在自然语言处理中，情感分析的 F1 Score 可以到 90%+。而在金融收益率预测中，即使是顶级量化机构的截面收益率预测模型，R² 通常也在 1%~5% 之间。一个 IC（信息系数）达到 0.05 的因子已经被认为是有价值的。

信噪比极低的直接含义是：金融市场中绝大部分价格波动是随机的（或者说，是我们无法用已知特征解释的）。你的模型只需要——也只能够——从巨大的噪声中提取出微弱的边际信号。

这对ML建模方式有深远影响。首先，过拟合是最大的敌人。在信噪比极低的环境中，复杂模型（如深层神经网络、未剪枝的决策树）极容易学到噪声中的虚假模式。训练集上的 R² 可能达到 30%，但测试集上立刻跌至 0 甚至为负。其次，模型评估需要更多数据。由于信号微弱，你需要大量样本才能统计性地判断一个策略是否真的有效（而非运气好）。最后，简单模型往往更可靠——线性模型加上精心设计的特征，在金融领域的表现常常优于端到端的复杂模型。

对从 Kaggle 竞赛或学术ML研究转入量化领域的人而言，最需要调整的心理预期是：你的模型不需要"很准"，只需要在大量交易中保持微弱但稳定的正向优势。年化 R² 为 3% 的模型如果足够稳定，就可以通过组合构建和杠杆管理产生可观的收益。

2.4.2 非平稳性

在ML术语中，金融数据面临严重的 concept drift（概念漂移）问题。市场的统计特性——均值、方差、特征与标签之间的关系——会随时间发生根本性变化。

以A股为例，2014-2015年的杠杆牛市中，动量因子（买入近期涨幅大的股票）表现极佳；而在2018年的单边熊市中，同一个因子可能严重亏损。2017年的"核心资产"行情中，大市值、高ROE的白马股大幅跑赢小盘股；而2021年初之后，风格又急剧反转。一个在某一市场环境下训练的模型，在环境切换后可能完全失效。

非平稳性意味着你不能简单地用过去五年的全部数据训练一个模型，然后期望它在未来持续有效。这是金融建模的根本性困难之一。

ML类比：想象你训练了一个垃圾邮件分类器，但每隔几个月，垃圾邮件的特征就会完全改变（因为发送者也在进化）。而且更麻烦的是，在金融市场中，你的模型本身的行为也会改变市场——如果所有人都用同一个模型，那个模型就会失效。这就是金融市场作为"自适应系统"的本质。

应对非平稳性的实操方法

以下是从简单到复杂的4种实用方案：

方法 核心思想 优点 缺点 适用场景
滚动窗口训练 固定长度窗口（如36个月）向前滑动，每期重训模型 简单可靠，自动遗忘旧信息 窗口长度需要调优；丢弃早期可能仍有价值的数据 月频选股策略的标准做法
指数衰减加权 所有历史数据都保留，但赋予近期样本更高权重（权重∝e^{-λt}） 保留全部数据又偏重近期；平滑过渡无"窗口断裂" 衰减系数λ需要调优 配合树模型的sample_weight参数使用
Regime条件模型 先识别市场状态（牛/熊/震荡），对每种状态训练独立模型或调整参数 针对性强，不同环境用不同策略 状态识别本身可能滞后；某些状态样本不足 择时信号与选股模型结合时
在线学习 / 增量更新 模型持续从新数据中学习，不完全重训（如FTRL、在线梯度下降） 适应速度最快，计算成本低 可能对噪声过度反应；对灾难性遗忘敏感 高频策略或因子快速衰减的场景

实践建议：大多数月频策略用滚动窗口+指数衰减加权即可。Regime条件模型适合在回撤较大时切换防守模式。在线学习更适合日内或高频场景。多种方法可以叠加使用。

2.4.3 序列自相关与i.i.d.违背

机器学习中最基本的假设之一是样本独立同分布（i.i.d.）。这意味着你可以随机打乱数据、划分训练集和验证集，每个样本提供的信息量相同且互不依赖。金融时间序列数据严重违背这一假设。

首先是时间序列自相关。今天的股价与昨天的股价高度相关（日收益率的自相关虽然很弱，但特征层面的自相关很强）。如果你在训练集中包含了周一到周四的数据，然后用周五的数据做验证，你的模型很可能利用了前四天的"信息泄露"。这就是为什么金融数据不能用随机K-Fold交叉验证，必须使用时序切分（Time-Series Split）。

其次是截面相关性。同一天的所有股票受同一个市场环境影响。如果大盘暴跌3%，几乎所有股票都会下跌。这意味着5000只股票在同一天的数据并不等于5000个独立样本——它们的有效独立样本数可能只有几十个（等于独立因子的数量）。

这两个问题共同导致了一个严重后果：你的有效样本量远小于表面上的数据条数。假设你有10年 x 250天 x 5000只股票 = 1250万条数据，看起来很多；但考虑到时间序列的自相关和截面的共同因子结构，真正独立的信息量可能只等价于几千个独立观测。这也解释了为什么金融模型如此容易过拟合——看似大量的数据实际上并没有那么多信息。

2.4.4 多重共线性

在量化研究中，研究者通常会构造大量因子（特征）——可能是几十个甚至上百个。然而，这些因子之间往往高度相关。例如：5日均线和10日均线高度相关；市盈率（PE）和市净率（PB）相关性很强；不同定义的"动量因子"之间几乎衡量的是同一件事。

多重共线性在ML中会导致几个问题：

  • 模型不稳定：对于线性模型，高度共线的特征会导致系数估计极不稳定（方差膨胀）。今天训练得到正系数，明天换一批数据可能变成负系数。
  • 特征重要性误导：当两个高度相关的特征进入模型时，重要性可能被随机分配给其中一个，导致你对因子的理解产生偏差。
  • 降维必要性：100个因子中可能只有10-15个真正独立的信息源。使用PCA、因子正交化或LASSO等方法进行降维/筛选几乎是必须的步骤。

在实践中，VIF（方差膨胀因子）分析、因子相关性热力图、以及L1正则化是处理多重共线性的常用工具。一个好的因子库不在于因子数量多，而在于因子之间提供了互补的、独立的预测信息。

2.5 特征构造的层次

从原始行情数据到最终送入ML模型的特征，通常需要经历多个层次的加工。每一层都在原始信息的基础上增加了抽象度和（希望的）预测能力。

原始行情数据（OHLCV）
↓
技术指标（MA / RSI / MACD / Bollinger Bands）
↓
横截面因子（排名标准化 / 行业中性化）
↓
复合因子（因子的因子 / 非线性组合）

第一层：原始行情数据。最基础的 OHLCV（开盘价、最高价、最低价、收盘价、成交量）数据。这些数据本身的预测能力有限，但包含了所有后续加工的信息基础。原始数据需要经过复权处理（解决除权除息导致的价格跳变）才能使用。

第二层：技术指标。这是对原始 OHLCV 数据进行时间序列变换的结果。常见的技术指标包括：移动平均线（MA）衡量趋势方向、RSI（相对强弱指标）衡量超买超卖程度、MACD 衡量趋势动能、布林带（Bollinger Bands）衡量波动性等。从ML角度看，技术指标本质上是手工设计的时序特征——它们将时间窗口内的价量信息压缩为一个标量值。

第三层：横截面因子。技术指标是单只股票的时间序列特征，而横截面因子是将这些特征放在全市场所有股票中进行相对排序和标准化。例如，将每只股票的20日动量在同一天的全市场中排名，然后标准化到 [-1, 1] 区间。这一步的意义在于：消除市场整体水平的影响（市场中性化），使因子值在不同时间点之间可比。行业中性化是另一个常见操作——去除行业因素的影响后，才能看到个股层面的相对强弱。

第四层：复合因子。将多个基础因子通过线性组合或非线性方法合成为更强的复合因子。传统做法是用IC加权；ML的做法则是让模型自动学习因子间的组合关系——这本质上就是让模型完成"因子的因子"这一步。后续章节中介绍的各种ML模型，都可以看作是不同的因子复合方法。

2.6 数据处理陷阱

金融数据处理中有许多看似细微、实则致命的陷阱。它们不会让你的代码报错，但会让你的回测结果变得毫无意义。以下三个是最常见也是最危险的。

陷阱一：复权问题

股票在除权除息后，价格会出现跳变。例如，一只10元的股票10送10后，价格变为5元，但投资者的实际收益为零。如果不做复权处理，你的模型会把这次"价格腰斩"误认为是暴跌，产生错误的信号。

A股有两种复权方式：前复权（将历史价格向下调整以匹配当前价格）和后复权（将当前价格向上调整以匹配历史价格）。前复权的问题是历史价格会随着新的除权事件不断变化，导致你的历史因子值在不同时间计算结果不同；后复权则保持历史一致性。建议在策略回测中使用后复权价格计算收益率，在因子计算中使用后复权或不复权+手动处理除权日。

陷阱二：停牌填充

A股股票可能因重大事项停牌数日甚至数月。停牌期间没有真实的成交价格和成交量。问题在于：如何处理停牌期间的数据？

常见做法包括：用停牌前最后一个交易日的收盘价填充、直接标记为NaN跳过、或使用行业指数的涨幅模拟。每种方法都有缺陷。填充最后价格会导致"停牌期间动量为零"的假象；标记NaN会导致某些因子无法计算；使用行业指数模拟则引入了假设性数据。更重要的是，停牌股票不可交易——如果你的模型选中了一只停牌的股票，这笔交易根本无法执行。策略中必须加入可交易性过滤。

陷阱三：Point-in-Time（时点数据）问题

这是最隐蔽也最严重的未来信息泄露来源。以财报数据为例：某公司2024年Q1的财报（报告期2024-03-31），实际公告日可能是2024-04-28。如果你在4月1日就使用了Q1的财报数据来做选股决策，你就使用了"未来信息"——因为在4月1日这个时点，该数据尚未被市场获知。

正确做法：始终使用数据的实际发布日（公告日）而非报告期来对齐时间轴。构建因子时，每个时点只能使用在该时点之前已经公开的信息。很多数据库提供了 Point-in-Time 版本的数据（如 Wind 的PIT财报），这是回测准确性的重要保障。

除了上述三大陷阱，还需注意：涨跌停板期间的价格和成交量可能不反映真实供需、新股上市首日的异常波动需要特殊处理、指数成分股调整（幸存者偏差）会扭曲回测结果。数据处理的每一步都需要问自己：在实盘交易的那个时点，我真的能获取到这个数据吗？

2.7 与ML建模的关联

如果你来自ML背景，以下概念映射可以帮助你快速建立金融量化与ML之间的认知桥梁：

ML概念 → 量化金融对应

  • Feature Engineering（特征工程） → 因子构造（Alpha因子研究）
  • Data Leakage（数据泄露） → 未来信息（Look-Ahead Bias）
  • Class Imbalance（类别不平衡） → 收益率分布的偏态与厚尾
  • Concept Drift（概念漂移） → 市场Regime切换（牛熊转换、风格轮动）
  • Cross-Validation（交叉验证） → 时序切分 + 组合型验证（Purged K-Fold）
  • Regularization（正则化） → 因子剪枝 / 多因子中的因子筛选
  • Ensemble Methods（集成方法） → 多策略/多因子组合
  • Hyperparameter Tuning（超参数调优） → 回测参数选择（需警惕过拟合）

需要特别强调的是，在金融领域，Data Leakage（未来信息泄露）的后果远比其他ML任务更严重。在医学图像识别中，数据泄露会导致验证集指标虚高，但不会直接造成经济损失。在量化交易中，未来信息会让你的回测报告呈现出完美的收益曲线，引诱你投入真金白银，然后在实盘中血本无归。

另一个重要差异是标签的定义。在分类任务中，标签是确定的（一张图片就是猫或者不是猫）。而在量化交易中，"预测目标"的定义本身就是一个研究问题：是预测下一日的收益率？下五日？下一个月？是预测绝对收益还是相对于基准的超额收益？是回归问题还是分类问题（涨/跌/平）？每种选择都会导致完全不同的模型表现和策略特性。

最后，金融ML有一个独特的反馈效应：当一个有效的预测模型被大量使用后，它所捕捉的模式（Alpha）会逐渐消失——因为所有人都按同一个信号交易，信号就被"消化"了。这意味着ML模型在金融中的"保质期"是有限的，持续的因子研发和模型更新是量化团队的核心竞争力。

2.8 本章小结

本章要点

  • 数据类型：A股数据分为行情数据、基本面数据和另类数据三大类，日频OHLCV是入门首选。
  • 频率选择：日频数据在可获得性、交易成本和策略可行性上最为均衡，适合大多数ML量化策略。
  • 低信噪比：金融预测的 R² 通常低于 5%，模型需要保持简单以避免过拟合，对"微弱信号"保持正确预期。
  • 非平稳性：市场统计特性随时间变化（concept drift），需要滚动训练和regime感知。
  • i.i.d.违背：不能随机划分数据，必须使用时序切分；有效样本量远小于数据条数。
  • 多重共线性：因子间高度相关，需要降维或正则化以获得稳定的模型。
  • 特征工程层次：从 OHLCV → 技术指标 → 横截面因子 → 复合因子，逐层抽象。
  • 数据陷阱：复权方式、停牌处理、Point-in-Time 是三大最常见的数据处理错误来源。
  • 核心原则：在任何时点，只使用该时点之前已公开的信息——这是回测诚信的底线。

2.9 延伸阅读

推荐资源

  • 《Advances in Financial Machine Learning》 - Marcos López de Prado：金融ML领域的奠基之作，对数据标注（Triple Barrier Method）、交叉验证（Purged K-Fold）、特征重要性等问题有深入讨论。
  • 《Quantitative Equity Portfolio Management》 - Ludwig Chincarini & Daehwan Kim：系统介绍因子模型和因子构造方法的经典教材。
  • 《Evidence-Based Technical Analysis》 - David Aronson：从统计学角度审视技术分析，讨论数据挖掘偏差和多重假设检验问题。
  • Tushare Pro 文档（tushare.pro）：A股最常用的Python数据接口之一，文档详细介绍了各类数据字段和获取方式。
  • 聚宽（JoinQuant）研究文档：提供了大量A股因子研究的实例和数据处理规范，适合入门参考。
  • 《A股市场因子投资实证研究》 - 石川等：国内学者系统性地对A股市场因子进行了实证检验，数据处理部分值得精读。
