第九章（实操篇）

从零构建一个多因子选股策略

用一个具体案例走完全流程——每一步说明做什么、为什么、以及容易踩的坑

引言

前八章讲了"是什么"和"为什么"。这一章用一个具体案例串联所有知识点，回答"怎么做"。

我们的目标是：构建一个月频调仓的中证500增强策略，使用ML模型从多个因子中选股，在A股日频数据上进行回测验证。这是量化私募最常见的策略类型之一。

全流程分为9个步骤。每个步骤我们会说明：做什么、为什么这样做、常见错误是什么。

案例设定

  • 策略类型：中证500指数增强（相对基准赚超额收益）
  • 选股范围：中证500成分股 + 过去一年曾为成分股的股票
  • 调仓频率：月度（每月第一个交易日）
  • 持仓数量：50只
  • 基准指数：中证500
  • 回测区间：2018-01 至 2023-12（6年）

步骤一：确定股票池

做什么

确定每个调仓日可供选择的股票范围。我们使用中证500成分股作为基础池，并加入过去12个月曾经是成分股但被调出的股票（避免频繁换仓的边界效应）。

在此基础上，每个调仓日需要剔除以下股票：

  • ST/*ST股票（经营异常，涨跌停幅度不同）
  • 上市不足60个交易日的新股（价格未稳定，数据不充分）
  • 调仓日停牌的股票（无法买入）
  • 调仓日涨停的股票（封板买不到）

为什么

股票池的设计直接决定了策略的可投资性。一个过大的池（如全A股）会引入大量小盘股和问题股，增加执行难度；一个过小的池（如沪深300）可能限制alpha空间。中证500是多数量化私募选择的标的——流动性尚可，alpha空间充足。

常见错误

  • 成分股回溯偏差：使用当前日期的中证500成分去回溯历史。正确做法是使用每个历史时点的真实成分（Point-in-time成分数据）。
  • 不剔除涨停股：回测中选入涨停股并假设买入成功。实际上涨停板买不到，这会严重高估策略收益。
  • 忽略停牌：停牌股无法交易，如果入选后在持仓期内停牌，还需要考虑资金占用和复牌后的风险。

步骤二：因子选择与计算

做什么

选择一组候选因子，在每个调仓日的前一天收盘后计算各股票的因子值。我们选择5个经典因子覆盖不同维度：

因子名称 维度 计算方式 逻辑
20日动量 动量 过去20个交易日的收益率 短期趋势延续
EP（盈利收益率） 价值 TTM净利润 / 总市值 低估值股票有更高期望收益
ROE_TTM 质量 过去12个月净利润 / 平均净资产 盈利能力强的公司更值得持有
波动率 低波动 过去60日收益率的标准差 低波动异象：低风险股票反而收益更高
换手率均值 流动性/情绪 过去20日日均换手率 高换手可能反映过度投机，未来收益偏低

为什么选这5个

因子选择的核心原则是多维度覆盖、低相关性。5个因子分别来自动量、价值、质量、波动率、流动性五个不同维度，相互间相关性较低。这样即使某个因子暂时失效，其他因子仍能提供信息。

这类似于ML中的特征选择——不是特征越多越好，而是要选择信息互补、低冗余的特征组合。

常见错误

  • Point-in-time违规：计算ROE时使用了尚未发布的财报数据。比如在2023年3月15日计算时，2022年年报可能要到4月才发布，此时只能用到2022年三季报。
  • 复权问题：计算动量时未正确复权（应使用后复权价格计算收益率）。
  • 因子方向不一致：有些因子是"越大越好"（EP、ROE），有些是"越小越好"（波动率、换手率）。在输入模型前需要统一方向。

步骤三：因子预处理

做什么

对原始因子值进行标准化处理，使其可以被模型有效使用。处理流程：

缺失值处理
→
极端值截断
→
行业市值中性化
→
标准化

缺失值处理：缺失值用行业中位数填充（而非全市场均值，因为不同行业的因子分布不同）。如果某只股票缺失因子超过2个，直接从候选池中剔除。

极端值截断（Winsorize）：将超过±3倍标准差的值截断到边界。金融数据有肥尾分布，极端值会扭曲标准化后的分布。

行业市值中性化：对每个因子做截面回归——将因子值对行业哑变量和对数市值做回归，取残差作为中性化后的因子。目的：去除因子中的行业和市值成分，使因子反映纯粹的alpha信息。

标准化（Z-Score）：减去截面均值，除以截面标准差。使不同因子的量纲统一，方便模型处理。

为什么

中性化是最关键的一步。如果跳过行业中性化，你的"价值因子"可能只是在告诉你"银行股PE低"——这不是alpha，这是行业特征。中性化后的因子才能回答："在同行业、同市值的公司中，谁被低估了？"

ML类比：行业市值中性化≈去除confounding variable。就像在做因果推断时控制混杂变量一样，你希望因子的预测力来自真正的选股信号，而非行业或规模的代理。标准化≈feature scaling，确保不同尺度的特征被模型平等对待。

常见错误

  • 用全样本做标准化：用整个回测期（2018-2023）的统计量做Z-Score。这引入了未来信息。正确做法：每个截面（每个月）独立计算均值和标准差。
  • 先标准化后中性化：顺序错了。应该先中性化再标准化，否则中性化的回归系数受极端值影响。

步骤四：标签构造

做什么

为每个调仓日的每只股票构造标签。我们使用未来20个交易日的市场超额收益的截面排名分位数作为标签。

具体计算：

  1. 计算每只股票从T+1日开盘到T+20日收盘的收益率
  2. 减去同期中证500指数的收益率，得到超额收益
  3. 在当期所有股票中排名，转为0-1的分位数（0=最差，1=最好）

为什么

为什么用T+1开盘而非T日收盘：T日收盘时产生信号，T+1才能下单买入。如果从T日收盘开始算收益，相当于假设你在产生信号的瞬间就能买入——这在T+1制度下不可能。

为什么用超额收益：我们关心的是选股能力（alpha），不是对大盘方向的判断（beta）。减去指数收益后，标签只反映"谁比平均水平好"。

为什么转为排名分位数：原始收益率分布有肥尾和偏态（少数股票涨停贡献极端值）。排名分位数将标签转为均匀分布，消除异常值影响，模型训练更稳定。

常见错误

  • 标签泄露：标签中包含了调仓日当天的信息（如用T日收盘价作为买入价）。
  • 持有期与调仓频率不匹配：如果月度调仓但标签只看5天收益，那标签覆盖期和实际持有期不一致，模型优化的目标和实际表现会脱节。
  • 停牌股的标签：停牌期间无真实价格，如果简单用停牌前价格填充，会产生虚假的0收益。应标记为缺失值并剔除。

步骤五：训练集构造与模型训练

做什么

使用滚动窗口方式构造训练集，训练一个LightGBM模型。

滚动窗口设定

  • 训练窗口：过去36个月的数据（约36×500=18000个样本）
  • 验证窗口：训练窗口之后的6个月（用于early stopping和参数选择）
  • 预测目标：验证窗口之后的1个月（真正的样本外）
  • 窗口滑动：每月重新训练一次（每次向前滑动1个月）

训练数据格式：每一行是一个"股票×月"的样本。特征是5个预处理后的因子值，标签是未来20日超额收益排名分位数。

模型选择（LightGBM）的原因：

  • 天然处理截面数据（表格数据是树模型的优势领域）
  • 对特征尺度不敏感（虽然我们已经做了标准化）
  • 能捕捉非线性和交互效应
  • 训练速度快，适合每月重训
  • 不容易像神经网络那样严重过拟合小样本

关键超参数方向：

参数 建议范围 考量
num_leaves 16-64 过大容易过拟合截面数据
learning_rate 0.01-0.05 较低的学习率配合更多的树
n_estimators 200-1000 配合early stopping自动确定
subsample 0.7-0.9 行采样，降低过拟合
reg_lambda 1-10 L2正则化，控制复杂度

为什么

为什么用滚动窗口而不是全样本训练：金融市场是非平稳的。2015年牛市的规律不一定适用于2022年的熊市。滚动窗口确保模型只使用"近期"数据，能自适应市场变化。36个月是平衡样本量和时效性的常见选择。

为什么每月重训：因子的有效性会随时间变化（regime change）。月度重训让模型持续更新对当前市场状态的理解。但也不能太频繁——每日重训的样本变化极小，增加的计算成本无意义。

ML类比：滚动窗口训练≈online learning的一种变体。你不是用一个固定模型预测所有未来，而是持续用最新数据更新模型。验证窗口的作用≈validation set用于early stopping和超参选择。关键区别：这里的split必须严格按时间——不能有任何"未来→过去"的信息流。

常见错误

  • 训练集和验证集时间重叠：如果标签是20天收益，训练集最后一个月和验证集第一个月存在标签重叠（训练最后的样本在计算20天收益时用到了验证期的价格）。需要设置purge gap（约1个月）。
  • 超参搜索在全样本上做：应在训练期+验证期上做超参搜索，绝不触碰测试期数据。否则测试期结果不可信。
  • 模型太复杂：5个因子×500只股票×36个月≈18000样本。用太深的树（num_leaves>128）很容易过拟合。在金融低信噪比环境下，简单模型往往更稳健。

步骤六：生成预测与选股

做什么

在每个调仓日，用最新训练好的模型对当期股票池中所有股票进行打分，然后选出得分最高的50只股票。

当期因子值（已预处理）
→
模型预测打分
→
排名筛选Top-50
→
约束过滤
→
最终持仓

约束过滤（在Top-50基础上再过滤）：

  • 剔除调仓日涨停的股票（买不到）→ 用排名下一位替补
  • 剔除调仓日停牌的股票 → 同上替补
  • 检查行业集中度：单行业不超过10只（防止行业过度集中）

为什么

模型打分只是"理论最优"，约束过滤将其转化为"可执行持仓"。涨停买不到、停牌进不去，这些是A股的物理限制，必须在选股阶段就处理，而不是留到执行时被动应对。

常见错误

  • 用未来信息过滤：调仓日开盘前做决策，但使用了调仓日收盘后才知道的信息（如当天是否涨停）。正确做法：使用前一日的涨跌停状态做预判，或者将调仓时点设为开盘后15分钟（确认开盘状态后再下单）。
  • 不设替补规则：剔除涨停股后持仓不足50只，实际仓位低于计划。应该有明确的替补逻辑。

步骤七：组合权重与调仓执行

做什么

确定50只股票各自的权重，并与上期持仓对比确定交易清单。

权重方案：行业内等权。

  1. 先按行业分配权重：每个行业的总权重 = 该行业在中证500中的权重（跟踪基准的行业分布）
  2. 行业内的股票等权分配

调仓执行逻辑：

  • 对比本期目标持仓与上期实际持仓
  • 新增股票：需要买入
  • 继续持有的股票：可能需要调整权重
  • 被移除的股票：需要卖出（注意：如果卖出时该股跌停，无法卖出，需保留到下一次可交易时）

为什么用行业内等权

行业权重跟踪基准 → 保证策略的超额收益来自"行业内选股"而非"行业轮动"。这使得策略的风格纯粹，归因清晰。行业内等权 → 简单、稳健，不需要额外的协方差矩阵估计。

换手率控制

假设本月Top-50与上月有30只重叠、20只更换。单边换手率 = 20/50 = 40%。年化单边换手 = 40% × 12 = 480%，双边约960%。

如果单边交易成本（佣金+印花税+滑点）= 0.3%，年交易成本 = 960% × 0.3% ≈ 2.9%。

这个水平对于月频策略是可接受的。但如果换手更高，就需要加入换手约束：如果新入选股票的得分与被替换股票得分差距不大（比如<0.5个标准差），则保留原持仓不做替换。

常见错误

  • 忽略卖出限制：跌停股无法卖出。回测中需要模拟这个约束——如果当天跌停则延迟到下一个可交易日卖出。
  • 不考虑资金到位时间：T+1制度下，今天卖出的资金明天才能用于买入。如果需要"卖A买B"，在严格模拟中需要分两天执行。

步骤八：回测与绩效评估

做什么

按照上述规则在2018-2023年的历史数据上模拟交易，计算策略的绩效指标。

回测设定：

参数 设定值 说明
初始资金 1000万 适合中证500策略的容量
买入价格 调仓日开盘价 × (1+0.1%) 模拟滑点
卖出价格 调仓日开盘价 × (1-0.1%) 模拟滑点
佣金费率 万分之二（双边） 机构账户水平
印花税 千分之0.5（仅卖出，2023年8月起） A股现行规定
涨停不买入 是 模拟真实成交限制
跌停不卖出 是 模拟真实成交限制

评估指标清单：

指标 计算对象 及格线 优秀线
年化超额收益 策略收益 - 中证500收益 >8% >15%
超额收益夏普 超额收益的Sharpe >1.5 >2.5
超额最大回撤 超额收益曲线的MaxDD <10% <5%
信息比率(IR) 年化超额/超额波动率 >1.0 >2.0
月度胜率 超额为正的月份占比 >60% >75%
年化换手率 双边总换手 <15倍 <10倍

为什么

指数增强策略的评估核心是超额收益而非绝对收益。即使策略亏了10%，只要同期中证500跌了20%，你仍然有10%的超额——这正是客户付费购买的alpha。

单看超额收益还不够，需要同时看稳定性（IR、月度胜率）和风险（最大回撤）。一个年化超额20%但回撤15%的策略，不一定比年化超额12%但回撤4%的策略更好——因为后者的IR更高，策略更稳。

常见错误

  • 不扣交易成本：A股的交易成本不低（印花税+佣金+滑点约千三到千五单边）。月频策略年交易成本可达2-4%，这是必须纳入的。
  • 样本内当样本外用：用2018-2023全量数据训练一次模型，然后在同样的2018-2023上回测。这是严重的泄露。必须用滚动方式，只用过去数据训练、预测未来。
  • 忽略分年度表现：一个6年平均很好但有连续12个月回撤10%的策略，实盘中大概率会被提前终止。需要看分年度的超额是否稳定。

步骤九：诊断与迭代

做什么

回测完成后，对结果进行归因分析，找到策略的优势和不足，指导下一轮迭代。

归因分析维度：

分析维度 目的 如果发现问题
分年度超额 是否所有年份都正 某年为负 → 分析该年市场特征，策略是否对某种regime不适应
行业归因 超额来自行业内选股还是行业偏离 如果主要来自行业偏离 → 中性化不充分
因子贡献 哪个因子贡献最大 如果单因子贡献>80% → 过度依赖，需增加因子多样性
换手归因 高换手是否带来了等比例的超额 高换手低增量收益 → 模型信号不稳定，加入换手约束
回撤分析 最大回撤发生在何时、为何 特定事件（如2018年去杠杆）→ 可接受；无特殊原因 → 模型可能过拟合

常见的迭代方向：

  • 如果IC偏低 → 增加因子数量、尝试更复杂的因子（如量价因子、日内因子）
  • 如果换手太高 → 添加换手约束、使用更长的label持有期、增加模型正则化
  • 如果某年回撤大 → 分析该期间的市场特征，考虑引入择时信号控制仓位
  • 如果行业偏离严重 → 加强行业中性化约束
  • 如果模型过拟合 → 减少num_leaves、增加正则化、减少因子数

ML类比：这一步≈error analysis。和ML项目一样，不是一次训练就结束。你需要看模型在哪里犯错、为什么犯错、如何改进。区别在于：ML中的error analysis看的是单样本级别（哪些图片被错分），量化中的error analysis看的是时间段级别（哪个月表现差、为什么）。

本章小结

关键要点

  • 一个完整的选股策略涉及9个步骤，每个步骤都有可能引入偏差或错误
  • Point-in-time原则贯穿始终：任何时刻只能使用该时刻之前可获得的信息
  • T+1制度影响从标签构造到执行的整个链路
  • 因子预处理（特别是行业市值中性化）决定了alpha的纯粹度
  • 滚动窗口训练是应对金融数据非平稳性的标准做法
  • 评估指标看超额而非绝对，看稳定性而非极值
  • 策略开发是一个迭代过程，第一版回测结果不好是正常的
  • 交易成本和执行约束必须纳入回测，否则结果不可信
